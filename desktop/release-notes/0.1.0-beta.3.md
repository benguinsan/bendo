## Changes since beta.2

- Doro `create_task` / `update_task` (with `date`) send `tzOffsetMinutes` from the user's machine, so the schedule uses local noon instead of UTC (late-night "today" no longer lands on tomorrow; no `SCHEDULE_IN_PAST` west of UTC).
- Runtime log file masks URL query tokens (`?token=` / `access_token=` → `[REDACTED]`); terminal output unchanged.

Not in this build: removal of `POST /api/discord-identity` is a Vercel-side change and ships with the next `bendo-app` deploy.
