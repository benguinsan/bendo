## Changes since beta.3

- Doro `create_task` / `update_task` compute `tzOffsetMinutes` for the requested date (local noon), so DST zones no longer get `scheduledAt` shifted by one hour on dates across a DST switch.
- Web task form (bundled Next) uses the same per-date offset.
- Harness stdout/stderr are buffered by line before logging, so a `?token=` split across pipe chunks is still redacted in the runtime log.

Not in this build: Vercel-side changes (`POST /api/discord-identity` removal, web per-date offset on the hosted site) ship with the next `bendo-app` deploy.
